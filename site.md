# Гид по PARI

Текстовая версия [главной страницы](https://parimatch.cfd/).

Это независимая справочная страница о спортивной линии. Материалы предназначены для аудитории 21+ в России.

## Спортивная линия

В линии PARI есть футбол, хоккей, теннис и киберспорт. Прематч — события до начала матча, live — во время игры.

## Виды ставок

- Ординар — ставка на один исход
- Экспресс — несколько исходов в одном купоне
- Система — несколько комбинаций с отдельным расчетом каждой
